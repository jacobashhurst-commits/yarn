# Welcome to Yarn

Your meetings. Your memories. Your computer.

Yarn records your meetings, figures out who said what, and turns conversations into searchable notes and a daily brief of what matters.

No subscriptions. No cloud AI processing. Your conversations stay on your Mac.

## Which download

- **Yarn.Setup.Apple.Silicon.zip** is the installer for most places. Yarn Setup downloads the speech model.
- **Yarn.Setup.Japan.Apple.Silicon.zip** is about 1.6 GB. The speech model is already inside. Use this where that download stops before it finishes.

## What's new

- On a Mac, Yarn uses the graphics chip to separate voices when that path is available. If it is not, the processor does it and the transcript is kept.
- A recording chosen in Downloads is copied in so Yarn can read it. A long wav is accepted. Speech that sits on the last channel of a multi-channel file is kept.
- A wrong name can be corrected on the meeting. That changes that meeting. A saved voice is corrected under Speakers, and the clip stays with the person.

## Getting started

1. Download the zip that matches where you are, from the Assets section on this page.
2. Unzip it and double-click Yarn Setup.
3. Click Install Yarn and leave the window open.
4. Open Yarn and start recording.

If you already use Yarn, double-click Yarn Setup from this zip. That replaces the app. The first headphone call on this signed Yarn may need Yarn added once: click + under System Settings, Privacy & Security, Screen & System Audio Recording, and choose Yarn from the Applications folder in your home folder. On an older Mac that row is called Screen Recording.

Yarn currently supports Apple Silicon Macs.
