# Welcome to Yarn

Your meetings. Your memories. Your computer.

Yarn records your meetings, figures out who said what, and turns conversations into searchable notes and a daily brief of what matters.

No subscriptions. No cloud AI processing. Your conversations stay on your Mac.

## What's new

- Installing Yarn is a double-click. Open the zip and open Yarn Setup.
- Yarn is signed. A later install is the same app, so the headphone permission stays. The first headphone call on a Mac still asks once.

## Getting started

1. Download Yarn.Setup.Apple.Silicon.zip from the Assets section on this page.
2. Unzip it. You will see Start here.txt and Yarn Setup. Double-click Yarn Setup.
3. Click Install Yarn and leave the window open.
4. Open Yarn and start recording.

If you already use Yarn, double-click Yarn Setup from this zip. That replaces the app. The first install of this signed Yarn may need Yarn turned on once under System Settings, Privacy & Security, Screen & System Audio Recording. On an older Mac that row is called Screen Recording.

Yarn currently supports Apple Silicon Macs.
